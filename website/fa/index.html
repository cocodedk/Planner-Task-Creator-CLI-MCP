Planner Task Creator CLI MCP English

مدیریت تسک‌های Planner با هوش مصنوعی

تسک‌های Microsoft Planner را از خط فرمان یا از طریق دستیاران هوش مصنوعی با استفاده از پروتکل MCP ایجاد و مدیریت کنید.

Python CLI TypeScript پروتکل MCP Microsoft Graph متن‌باز
مشاهده در GitHub

ویژگی‌ها

  • Python CLI: رابط خط فرمان کامل با Typer و Rich
  • سرور MCP: سرور TypeScript/Node.js برای یکپارچه‌سازی با دستیار هوش مصنوعی
  • احراز هویت امن: جریان کد دستگاه OAuth2 با کش توکن
  • مدیریت تسک: ایجاد، فهرست، به‌روزرسانی و نظر دادن روی تسک‌های Planner
  • چندطرح: کار در چندین برنامه و سطل Planner

شروع سریع

  1. نصب Node.js 20+ و Python 3.12+
  2. کلون: git clone https://github.com/cocodedk/Planner-Task-Creator-CLI-MCP
  3. نصب وابستگی‌ها: npm install && pip install -r requirements.txt
  4. ساخت TypeScript: npm run build
  5. اجرای CLI: python planner.py --help
