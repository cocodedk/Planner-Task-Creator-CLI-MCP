Manage Planner Tasks with AI

Create and manage Microsoft Planner tasks from the command line or through AI assistants using the Model Context Protocol. Secure OAuth2 authentication included.

Python CLI TypeScript MCP Protocol Microsoft Graph Open Source
View on GitHub

Features

  • Python CLI: Full-featured command-line interface using Typer and Rich
  • MCP Server: TypeScript/Node.js server for AI assistant integration
  • Secure Auth: OAuth2 device code flow with token caching
  • Task Management: Create, list, update, and comment on Planner tasks
  • Multi-Plan: Work across multiple Planner plans and buckets

Quick Start

  1. Install Node.js 20+ and Python 3.12+
  2. Clone: git clone https://github.com/cocodedk/Planner-Task-Creator-CLI-MCP
  3. Install dependencies: npm install && pip install -r requirements.txt
  4. Build TypeScript: npm run build
  5. Run CLI: python planner.py --help
